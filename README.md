# 改道 DETOUR — V0.2 体素塔防（美术重构版）

一款使用 **Godot 4.x + GDScript** 开发的 3D 体素塔防游戏。第一关「废弃工厂」，参考《保卫萝卜》的经典塔防循环：建造炮塔 → 敌人出兵 → 自动攻击 → 获得金币 → 升级炮塔 → 下一波 → 保卫核心。

**V0.2 是一次完整的视觉升级**：在完全保留 V0.1 游戏逻辑与数值的前提下，重做了地图、道路、能源核心、建筑植被、炮塔与敌人模型、灯光环境与整套 UI。长期特色（体素地形破坏与动态改道）已预留接口（`PathManager.compute_dynamic_path` 基于 `AStarGrid2D`），留待后续版本实现。

---

## 一、启动方法

1. 安装 Godot 4.7 或更高版本（需支持 **Compatibility / GL Compatibility** 渲染器）。
2. 打开 Godot，选择「导入项目」，定位到本目录（含 `project.godot`）。
3. 打开后直接按 **F5** 或点击播放按钮运行主场景 `res://main.tscn`。
4. 主场景已设为默认启动场景。

> 项目已配置 `renderer/rendering_method="gl_compatibility"`，兼容 Web 导出与造化平台的浏览器运行环境。

---

## 二、操作方式

- **开始波次**：准备阶段可点底部「开始波次」提前出兵，或等待 12 秒准备时间自动开始。
- **建造炮塔**：点击地图上的青蓝色建造平台 → 弹出建造菜单 → 选择机枪塔 / 重炮塔 / 电磁塔。金币不足时无法建造。底部建造栏的三张炮塔卡可点击选中（高亮）。
- **升级 / 出售**：点击已建造的炮塔 → 弹出面板，可升级（最多 3 级）或出售（返还总投入的 60%）。
- **拆除废墟**：点击带橙色警示条的可破坏废墟，可花费时间拆除并获得 20 金币（后续版本将支持改变敌人路线）。
- **暂停**：点击「暂停」按钮或按 **空格键**。
- **加速**：点击「1×」按钮切换 1× / 2× 速度。
- **结算**：三波全部清完显示胜利界面；核心生命降到 0 显示失败界面。点「重新开始」重开一局。

## 四、V0.2 美术重构说明

本版本**只改视觉，不改逻辑**。所有游戏数值、地图路线（20×14 格）、10 个建造位与接口保持不变。

### 视觉升级要点
- **程序化材质库**（`detour_materials.gd`）：噪声纹理 + 粗糙度贴图 + 金属度/粗糙度差异，让石、混凝土、锈铁、木材、植被各有质感，告别纯色占位块。
- **地面与道路**：带明暗变化与磨损的细节石质地砖；浅灰混凝土板道路 + 黄黑警示边 + 转角连续结构 + 方向标线；MultiMesh 批量渲染碎石/落叶/杂草。
- **能源核心**：多层八角机械基座 + 环形能量装置 + 青蓝自发光晶体 + 旋转动画 + 点光源蓝色地面照亮，是全图视觉焦点。
- **敌人入口**：红橙色工业传送门 + 警示灯 + 能量幕。
- **建筑与植被**：两栋不同造型的废弃厂房（带阳台/窗/屋顶设备）、破损砖墙、工业管道、集装箱、铁丝围栏、废弃机械、油桶木箱、碎石堆；多簇不规则体素树冠组成的秋树 + 灌木枯草。
- **炮塔与敌人**：三种炮塔轮廓分明（双枪管 / 粗炮管俯仰后坐 / 旋转能量环），两种敌人多部件建模（四足机械虫 / 履带机甲），带受击、开火、死亡特效。
- **正交等距相机 + 暖色秋日光**：地图占满主画面；DirectionalLight3D 暖主光 + 冷补光、WorldEnvironment（AO / 阴影 / 柔和辉光 / 轻雾 / Filmic 色调映射）。
- **工业科幻 UI**：深色半透明面板 + 橙色交互强调 + 青蓝能源状态；程序化矢量图标（核心/金币/波次/炮塔）、核心血条与波次进度条、按钮悬停/选中/禁用状态，无默认 Godot 按钮样式。

## 五、项目结构

```
新建游戏项目/
├── main.tscn                      主场景（唯一入口）
├── project.godot                  工程配置
├── README.md                      本文档
├── preview_map.png                地图预览截图
├── preview_victory.png            胜利界面预览截图
├── scripts/
│   ├── detour_config.gd           全局参数集中管理（数值/配色/坐标）
│   ├── detour_materials.gd        V0.2 程序化材质库（噪声/粗糙度/金属度）
│   ├── voxel_factory.gd           体素几何体工厂 + MultiMesh 批量渲染
│   ├── detour_models.gd           炮塔/敌人/核心/门的 3D 模型构建（V0.2 重做）
│   ├── detour_props.gd            V0.2 场景道具库（建筑/围墙/树/集装箱/管道等）
│   ├── path_manager.gd            固定路线 + AStarGrid2D 动态改道预留接口
│   ├── detour_world.gd            地图生成（地砖/道路/装饰/灯光/正交相机，V0.2 重做）
│   ├── detour_enemy.gd            敌人（移动/减速/受击/血条/信号）
│   ├── detour_tower.gd            炮塔（索敌/旋转/开火/升级/出售）
│   ├── detour_projectile.gd       子弹与炮弹
│   ├── detour_ui.gd               V0.2 工业科幻风完整 UI（矢量图标/血条/进度条/结算）
│   └── detour_main.gd             主控（经济/波次/输入/特效/胜负）
└── addons/godot_ai/               Godot AI MCP 插件（用于 AI 辅助开发）
```

架构原则：**地图数据、游戏逻辑、视觉表现分离**。`detour_config.gd` 集中所有可调参数；视觉层（材质/模型/道具/世界/UI）与逻辑层（主控制器/敌人/炮塔/子弹/路径）解耦，节点名约定保持稳定。

## 六、技术说明

- 敌人：`CharacterBody3D`，沿固定路径点移动；`Area3D` 检测炮塔射程。
- 炮塔：多部件 3D 模型（底座/炮管/传感器分件），旋转跟随目标，优先级索敌（最接近核心者优先）。
- 特效：程序化枪口闪光、命中火花、爆炸与电磁环，Tween 动画。
- 渲染：GL Compatibility，正交等距相机，暖色主光 + 冷色补光，WorldEnvironment 后处理。
- 性能：大量重复细节（碎石/落叶/杂草）用 MultiMesh 批量渲染，避免海量独立节点。
