# 改道 DETOUR — V0.3.2 体素塔防（稳定版）

一款使用 **Godot 4.x + GDScript** 开发的 3D 体素塔防游戏。第一关「废弃工厂」，参考《保卫萝卜》的经典塔防循环：建造炮塔 → 敌人出兵 → 自动攻击 → 获得金币 → 升级炮塔 → 下一波 → 保卫核心。

**V0.3 是一次针对性的美术质量提升**：在完全保留游戏逻辑与数值的前提下，对地图材质、道路、建筑植被、炮塔、敌人、能源核心与摄像机进行了精修，让《改道》从可运行的塔防原型提升为具有统一美术风格的独立游戏早期版本。长期特色（体素地形破坏与动态改道）已预留接口（`PathManager.compute_dynamic_path` 基于 `AStarGrid2D`），留待后续版本实现。

---

## 一、启动方法

1. 安装 Godot 4.7 或更高版本（需支持 **Compatibility / GL Compatibility** 渲染器）。
2. 打开 Godot，选择「导入项目」，定位到本目录（含 `project.godot`）。
3. 打开后直接按 **F5** 或点击播放按钮运行主场景 `res://main.tscn`。
4. 主场景已设为默认启动场景。

> 项目已配置 `renderer/rendering_method="gl_compatibility"`，兼容 Web 导出与造化平台的浏览器运行环境。

---

## 二、操作方式

- **开始波次**：准备阶段可点底部「开始波次」提前出兵，或等待 12 秒准备时间自动开始。
- **建造炮塔（两种方式）**：
  1. 按 **1 / 2 / 3** 或点击底部炮塔卡进入建造模式；鼠标移到青蓝色平台会显示半透明炮塔与真实射程环，点击平台直接建造；金币不足或平台占用会给出状态栏反馈；**ESC** 或**右键**取消。
  2. 不选择炮塔时，直接点击平台仍会弹出原来的建造菜单，选择三种炮塔之一。
- **升级 / 出售**：点击已建造的炮塔 → 弹出面板，可升级（最多 3 级）或出售（返还总投入的 60%）；建造模式下点击已有炮塔也会切到该面板。
- **拆除废墟**：点击带橙色警示条的可破坏废墟，可花费时间拆除并获得 20 金币（后续版本将支持改变敌人路线）。
- **暂停**：点击「暂停」按钮或按 **空格键**。
- **加速**：点击「1×」按钮切换 1× / 2× 速度。
- **结算**：三波全部清完显示胜利界面；核心生命降到 0 显示失败界面。点「重新开始」重开一局。

## 四、V0.3 美术精修说明

本版本**只改视觉，不改逻辑**。所有游戏数值、地图路线（20×14 格）、10 个建造位与接口保持不变。V0.3 针对 V0.2「整体过浅、像积木」的问题做了定向提升。

### 精修要点
- **深化工地色调**：地面由浅米色改为**深灰 / 灰褐石砖**（程序化石砖纹理，带砖缝与倒角磨损），浅绿苔藓压暗为极小点缀；新增程序化裂纹纹理生成能力。碎石、落叶、裂缝、枯草密度提高，避免颜色过于统一。
- **实体化道路**：道路改为分段**浅灰混凝土板**（每格一块、留拼接缝、带磨损明暗），深色路基 + 黄黑警示边 + 八角连续转角 + 起终点标识板；方向箭头间隔加大，摆脱「只有黄线」的观感。
- **工业设施与植被**：建筑改为深灰石 + 锈橙金属配色；新增金黄秋树 / 橙红秋树（多簇不规则体素树冠）与倾倒机械残骸资产，控制植被密度不遮挡路线与炮塔。
- **炮塔精修**：三种炮塔视觉**放大约 20%**（下沉到模型内部几何，不覆盖根节点 scale，升级动画不受影响）；强化双枪管护罩 / 粗炮管后坐缓冲筒 / 能量环电弧尖刺与齿圈底座，机械细节更丰富。
- **敌人精修**：侦察虫增加头部护罩、触角与侧面装甲，机甲增加核心护框、双层肩甲、警示条与履带脚板，提升等距视角辨识度（不放大，保持碰撞与血条一致）。
- **能源核心**：新增外层防护罩肋架、顶部尖塔与更多能量粒子；**生命值视觉反馈**——核心血量越低，点光源越暗、闪烁越急并偏红，晶体脉动加快（`world.set_core_health_ratio()`）。
- **摄像机构图**：正交相机缩放收紧（size 18.8）并微调视线目标，地图完整显示、占据画面主要区域，核心与入口清楚可见、不被底部 UI 遮挡。

## 五、项目结构

```
新建游戏项目/
├── main.tscn                      主场景（唯一入口）
├── project.godot                  工程配置
├── README.md                      本文档
├── preview_map.png                地图预览截图
├── preview_victory.png            胜利界面预览截图
├── scripts/
│   ├── detour_config.gd           全局参数集中管理（数值/配色/坐标）
│   ├── detour_materials.gd        程序化材质库（噪声/石砖/裂纹/粗糙度/金属度）
│   ├── voxel_factory.gd           体素几何体工厂 + MultiMesh 批量渲染
│   ├── detour_models.gd           炮塔/敌人/核心/门的 3D 模型构建（V0.3 精修）
│   ├── detour_props.gd            场景道具库（建筑/围墙/三种树/集装箱/残骸等）
│   ├── path_manager.gd            固定路线 + AStarGrid2D 动态改道预留接口
│   ├── detour_world.gd            地图生成（地砖/道路/装饰/灯光/核心反馈/正交相机）
│   ├── detour_enemy.gd            敌人（移动/减速/受击/血条/信号）
│   ├── detour_tower.gd            炮塔（索敌/旋转/开火/升级/出售）
│   ├── detour_projectile.gd       子弹与炮弹
│   ├── detour_ui.gd               V0.2 工业科幻风完整 UI（矢量图标/血条/进度条/结算）
│   └── detour_main.gd             主控（经济/波次/输入/特效/建造预览/胜负）
├── tests/                          V0.3.2 持久化自动化测试（入口 run_tests.ps1）
├── docs/                           V0.3.1 自检报告、V0.3.2 补充测试报告、V0.4 动态地形技术方案
└── addons/godot_ai/               Godot AI MCP 插件（用于 AI 辅助开发）
```

架构原则：**地图数据、游戏逻辑、视觉表现分离**。`detour_config.gd` 集中所有可调参数；视觉层（材质/模型/道具/世界/UI）与逻辑层（主控制器/敌人/炮塔/子弹/路径）解耦，节点名约定保持稳定。

## 六、技术说明

- 敌人：`CharacterBody3D`，沿固定路径点移动；`Area3D` 检测炮塔射程。
- 炮塔：多部件 3D 模型（底座/炮管/传感器分件），旋转跟随目标，优先级索敌（最接近核心者优先）。
- 特效：程序化枪口闪光、命中火花、爆炸与电磁环，Tween 动画。
- 渲染：GL Compatibility，正交等距相机，暖色主光 + 冷色补光，WorldEnvironment 后处理。
- 性能：大量重复细节（碎石/落叶/杂草）用 MultiMesh 批量渲染，避免海量独立节点。
