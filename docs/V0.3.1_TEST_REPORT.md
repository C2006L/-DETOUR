- 重装机甲作为精英敌人有辨识度（150HP / 2 点核心伤害）。
- 单塔纯重炮/纯电磁偏弱（P3），属数值平衡观察，本轮按任务要求未调整难度。
- 单局时长约 1~2 分钟，节奏合理。

## 七、测试局限与如实说明

- 无头测试使用固定 60fps 加速模拟，与真实显示器刷新率下的交互手感可能有细微差异；但游戏逻辑（计时、移动、伤害、经济）按 delta 驱动，结论适用。
- 低血量 HUD 变红、核心光偏红等纯视觉效果，通过源码确认（条件分支明确）+ 无头数值验证，未做逐像素颜色断言（Godot 4.7 无头下主题色读取 API 不可用），记为代码审查项而非运行时断言。
- 真人 GUI 试玩（人工手动点击操作）尚未执行；本报告的"真人式策略"是脚本模拟波间补兵逻辑，非人工操作。建议用户按 F5 亲自试玩确认手感。
