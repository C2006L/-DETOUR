## 二、逐模块检查结论

### 1. 游戏主循环 — PASS
- 准备 12 秒倒计时准确（实测初始 11.98~12.0，逐帧递减）。
- 点击"开始波次"正确提前出兵；连续点击不重复出兵（`wave_active` 守卫，实测 wave 保持 1）。
- 敌人未处理完不会进入下一波（波次结束判定 `spawn_queue.is_empty() and enemies.is_empty()`）。
- 最后一波结束正确胜利结算；核心归零立即 `_end_game(false)` 并停止战斗。
- 胜利与失败状态互斥（实测胜/败标题各自唯一）。
- 重新开始后 gold=300 / core_hp=10 / wave=0 / time_scale=1 / paused=false / 废墟恢复 3 处，全部实测通过。
- 无卡死异常状态。

### 2. 地图与寻路 — PASS
- 敌人严格沿 `PATH_CELLS` 10 个点前进，`PathManager.progress_at()` 归一化进度正确。
- 地图铺在 XZ 平面、Y 为高度（`grid_to_world` 转换实测正确）。
- 转弯用 `lerp_angle`，无瞬移；两种速度敌人都能走完全程。
- 10 个建造平台与点击区域一致（`_pad_near` 0.72 半径），无非法位置建造。
- `AStarGrid2D` 预留接口不影响当前固定寻路（未被调用）。

### 3. 炮塔系统 — PASS（含 1 项 P1 已修复）
- 索敌优先 progress 最大（最接近核心）者，实测正确。
- 射程判定统一 XZ 平面距离（忽略高度），实测：XZ=2/Y=20 仍锁定、XZ=4.6 不锁定、边界 4.5 含等号。
- 目标死亡后切换目标、无目标停火，实测通过。
- 三种炮塔伤害/间隔与配置一致；机枪双管、重炮 1.4 格爆炸、电磁 35% 减速 1.5s 均实测正确。
- 升级伤害倍率实测 Lv1/Lv2/Lv3 = 3 / 4.35 / 6（电磁），射速倍率换算正确。
- **发现并修复 P1**：范围伤害遍历 `enemies` 时删除元素导致漏伤（详见 BUG-FIXES P1-1）。

### 4. 升级与出售 — PASS
- 费用、倍率、60% 返还、满级禁止、金币不足拒绝、出售后平台恢复，全部实测通过。
- 整数金币无小数取整问题（伤害是 float，金币是 int）。

### 5. 敌人系统 — PASS（含 1 项已验证的此前修复）
- 初始化、移动、受击、减速、死亡状态正确；血条 unshaded 材质与层级修复有效。
- 多塔同帧击杀只结算一次金币（`take_damage` 死亡守卫，实测 died 仅发 1 次）。
- 已死亡敌人从 `enemies` 移除并 queue_free，不再移动或攻击核心。
- 血条与真实 HP 同步（scale.x 与 position.x 实测随伤害更新）。

### 6. 波次系统 — PASS
- 三波数量精确：8 / (8+2) / (10+4) = 32，实测确认。
- 波次奖励 +40 只在第 1、2 波结束发放。
- 未生成敌人正确计入剩余数（HUD `enemies + spawn_queue`）。

### 7. 经济系统 — PASS（含 1 项 P1 已修复）
- 所有收支路径实测：初始 300、击杀、波次、废墟、建造、升级、出售。
- 金币不会为负（各操作前有 `gold >= cost` 检查）。
- 无重复点击刷钱、无出售再购买漏洞。
- **发现并修复 P1**：结算后仍可升级/出售/拆废墟（详见 BUG-FIXES P1-2）。

### 8. 废墟拆除 — PASS
- 仅合法废墟可拆，每处只奖励一次，防重标记 `clearing` 有效。
- 拆除后从数组移除、动画 Tween 正常 queue_free、可拆标识 Mark 存在。
- 重新开始后 3 处废墟恢复（实测）。
- 拆除不影响当前固定路径（本版本设计）。

### 9. 核心生命 — PASS

### 10. 暂停与倍速 — PASS

- 2× 倍速正确、切回 1× 恢复、重开恢复默认。

### 11. UI 与交互 — PASS（含 1 项 P2 已修复）
- HUD 核心/金币/波次数值与数据实时同步。
- 建造菜单/塔菜单显示与屏幕边界 clamp 正确，hide_menus 关闭及时。

### 12. 美术、动画与特效 — PASS
