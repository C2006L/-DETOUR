# 《改道 DETOUR》V0.3.2 持久化自动化测试

本目录保存 V0.3.1 自检中关键用例的可重复运行版本，以及 V0.3.2 补充的边界/交互用例。
**测试脚本长期保留，不再跑完即删。**

## 一、统一运行入口

在 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\GroupNewGame\新建游戏项目\tests\run_tests.ps1"
```

可选参数：

```powershell
# 指定其他 Godot 4.7 console 可执行文件
... -GodotExe "C:\Godot\Godot_v4.7.2-stable_win64_console.exe"

# 只跑断言套件，跳过完整对局冒烟
... -SkipSmoke
```

入口会依次运行两个 Godot 无头脚本，输出同时写入 `tests/last_run.log`（已加入 `.gitignore`）：

| 脚本 | 作用 | 退出码 |
|---|---|---|
| `test_runner.gd` | 50 项核心/边界自动化断言 | 有 FAIL 则 1，全 PASS 则 0 |
| `smoke_playthrough.gd` | 满塔三波通关 + 无塔三波失败 | 有 FAIL 则 1，全 PASS 则 0 |

也可单独运行（需自行设置 UTF-8 输出编码）：

```powershell
& "D:\godot\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe" `
  --headless --fixed-fps 60 --path "D:\GroupNewGame\新建游戏项目" `
  --script "res://tests/test_runner.gd"
```

## 三、覆盖范围

### `test_runner.gd`（50 项，全部 PASS）

- **范围伤害**：爆炸同杀 4 敌全部结算；单个侦察虫奖励 **10 金**，4 敌共 **40 金**，金币 300→340。
- **重复死亡**：同一敌人多次致命伤只发 1 次 `died`，只奖励 1 次 10 金。
- **重炮主目标**：单敌只受 28 伤害（150→122），爆炸不二次命中主目标。
- **电磁塔**：XZ=1 且高度 20 仍命中并施加 35% 减速；XZ=9 不受伤；高度不影响 XZ 判定。
- **暂停/倍速**：冻结敌人与准备计时、恢复移动、1×↔2× 与切回后复位。
- **波次**：第一波队列 8、连点不重复出兵、队列与敌人清空后 +40 金并进入准备。
- **经济**：建造 100、升级 90/150、满级拒绝、出售返还 340×60%=204、重复出售拒绝。
- **建造交互**：卡片/数字键选择、合法平台直建、占用与金币不足反馈、ESC/右键取消、未选择时保留原弹出菜单。
- **临界击杀**：敌人贴近核心时被击杀，核心不掉血。
- **UI 结构**：建造卡与 HUD 默认 `STOP`，不会把点击漏给地图。
- **窗口尺寸**：1280×720 / 1024×768 / 800×600 下弹出菜单按实际视口 clamp。
- **暂停时操作**：规划类操作（建造/升级/出售）允许，模拟计时仍冻结。
- **结算边界**：核心归零与最后敌人死亡同帧、失败面板不被波次逻辑覆盖、结算后四类操作与卡片选择均被拦截。
- **重开重置**：金币/核心/波次/塔/敌人/队列/废墟/暂停/倍速/倒计时全部复位。

### `smoke_playthrough.gd`（6 项，全部 PASS）

- 满塔三波通关（注入金币，3136 帧，核心 10/10）；无塔三波失败（3026 帧，核心 0）。
- 说明：满塔使用**测试注入金币 10000**，仅用于验证战斗/波次/结算链路，**不代表经济平衡结论**；经济平衡数据见 `docs/V0.3.1_TEST_REPORT.md` 第五部分的真实经济测试。

## 四、如实标记：未用无头测试替代的人工 GUI 项目

运行输出中标记为 `MANUAL` 的项目，必须在真实窗口人工试玩确认：

1. `T-BUILD-5` 半透明炮塔预览与射程环的显示效果（无头环境无法设置鼠标位置）。
2. 真实鼠标点击建造 / 升级 / 出售的手感与命中判定。
3. 点击 UI 是否不误触地图（自动化仅验证控件 `mouse_filter` 结构）。
4. 不同窗口尺寸下相机取景与文字可读性（自动化仅验证菜单位置 clamp）。

这些项目**不计入 PASS**，也不得用无头结果替代人工试玩结论。

## 五、环境说明

- 引擎：Godot 4.7.2-stable，Compatibility / GL Compatibility，Windows 11。
- 无头模式使用 `--fixed-fps 60` 按固定步长推进逻辑；与真实刷新率下手感可能有细微差异，但计时/移动/伤害/经济均为 delta 驱动，逻辑结论适用。
- 测试中会临时修改金币、敌人位置、窗口尺寸与暂停状态；每个用例按依赖顺序编排，**不要单独截取某个 case 执行**，应从统一入口运行。
- `CanvasItem` 拉伸下窗口像素与 `get_viewport().get_visible_rect().size` 可能不同，尺寸断言以后者为准。
